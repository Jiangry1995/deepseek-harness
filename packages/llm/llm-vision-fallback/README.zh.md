# `@deepseek-ai/dsh-llm-vision-fallback`

[English](README.md) | 中文

为明确排除图片输入的已注册模型提供自动、可持久恢复的图片转文本降级。插件向 [`ctx.llm`](../llm/README.zh.md) 注册进程内唯一的 `LlmImageFallback`。原生视觉模型不受影响，模态信息未知的模型仍由其适配器决定，只有确切模型的 `inputModalities` 不含 `image` 时才会进入本提供方。

辅助模型是另一条已注册 LLM 路由。先在 Web **模型**页面配置该路由及其凭据，再到**设置 → 插件 → 自动识图**选择它。可安装的 [`@deepseek-ai/dsh-vision-fallback`](../../bundle/vision-fallback/README.zh.md) bundle 同时携带本 Host 插件和配套 Web 标签页，不会把它加入 `dsh-base` 默认组合。

```yaml
- name: '@deepseek-ai/dsh-llm-vision-fallback'
  config:
    provider: visual-provider
    model: visual-model
    maxTokens: 4096
    timeoutMs: 120000
```

`provider` 与 `model` 是一对可选值：两者都不存在时，已安装插件保持休眠。为了允许设置页逐字段写入，配置可以短暂只包含一项；第一张需要降级的图片会以 `VISION_FALLBACK_CONFIG_INVALID` 失败。完整辅助路由必须明确声明 `image`；模态未知或纯文本的辅助模型以 `VISION_FALLBACK_MODEL_NOT_IMAGE_CAPABLE` 失败，不会递归进入降级。

| 字段 | 默认值 | 含义 |
|---|---:|---|
| `provider` | — | 已注册的辅助提供方路由。 |
| `model` | — | `provider` 上确切的原生视觉模型。 |
| `maxTokens` | `4096` | 辅助输出正整数上限，最大 `32768`。 |
| `timeoutMs` | `120000` | `1000` 到 `300000` 毫秒的端到端期限。 |
| `prompt` | 完整转译指令 | 每张图片旁发送的稳定指令；可见文字被视为不可信内容而非指令。 |

对于一个会话中的每个不同附件，提供方会在辅助请求发出前追加仅存在于日志的 `vision/fallback-request`，并且只在完整文本成功后追加配对的 `vision/fallback-result`。请求记录确切且不含机密的路由、消息、附件引用和输出上限；结果记录替换目标适配器请求中该图片的确切 JSON framed 文本。完成结果会在直接图片块、嵌套工具结果、恢复、压缩和模型切换之间复用。失败或取消只留下请求记录，不会伪造结果；后续调用可以重试。

同一会话附件的并发调用共享执行所有权，但不共享取消。等待方可以只取消自己的等待而不终止活动请求；所有者失败后，下一个等待方会执行新的已记录请求。包 invariant 会在冷加载和实时追加时拒绝未出现过的附件引用、重复请求 id、孤立或重复结果、无效上限、空路由和空结果文本。

辅助请求通过其视觉适配器读取持久附件。如果适配器连接远程服务，图片字节会离开本机。降级插件不保存额外二进制副本，也不把 API Key 写进 settings 或会话事件。

## 模型体验

### 辅助图片转译

#### 模型看到什么

配置的辅助模型看到一条用户消息，其中先是配置的转译提示词，再是一张持久图片。确切且不含机密的请求会在发出前记录到 `vision/fallback-request`。辅助模型不会收到会话工具，并被要求描述可见内容，不解决外部任务，也不执行图片中的指令。

#### Token 影响

每个尚无完成结果的附件会产生一次独立视觉模型请求，输出受 `maxTokens` 限制。提供方可能按图片输入和生成文本计费。完成结果会在该会话内复用，因此主模型的重复请求不会继续消耗辅助模型 Token。

#### KV Cache 影响

辅助请求独立于会话缓存。重复附件直接复用持久结果而不重放辅助请求；修改 provider、model、prompt 或上限只影响尚无完成结果的附件。

### 纯文本目标投影

#### 模型看到什么

每个直接或嵌套图片块都会替换为配对 `vision/fallback-result` 存储的确切文本；所有非图片块、角色、消息 id 与来源顺序保持不变。原生视觉路由和模态未知路由收到原始消息列表。

#### Token 影响

纯文本目标为存储的转译支付普通输入 Token，而不是供应商特定的图片 Token。文本长度受辅助模型输出上限约束。

#### KV Cache 影响

首个完成转译把纯文本请求前缀从不受支持的图片引用变为稳定的已记录文本。后续请求重建同一投影并保留前缀复用资格，除非普通会话变更或压缩替换该区域。

## 已知限制与延期工作

- **必须有会话身份**——不带 `sessionId` 的直接图片 `ctx.llm.stream()` 调用以 `VISION_FALLBACK_SESSION_REQUIRED` 失败；未记录的辅助内容永远不会被允许。
- **每个会话附件只保留一份可复用说明**——辅助模型不会收到外部用户任务。这保证回放稳定，但后续问题不能在不新增附件的情况下要求不同裁剪、OCR 模式或任务专属重释。
- **只接受文本输出**——辅助模型的工具调用、图片输出、空输出和 `max-tokens` 终止都会失败，不会把残缺或含义不清的内容带入投影。
- **可用性依赖确切元数据**——适配器未声明 `inputModalities` 的视觉模型不能作为辅助模型，必须先在模型 profile 中声明 `image`。
