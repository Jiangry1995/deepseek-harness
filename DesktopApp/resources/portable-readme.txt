DeepSeek Harness 绿色包

1. 解压到任意目录。
2. 双击 DeepSeek Harness.exe 启动。第一次启动会创建桌面快捷方式、开始菜单快捷方式，并在「设置 → 应用 → 已安装的应用」里登记卸载项。
3. 点关闭会询问：最小化到托盘（服务继续跑）或退出（停止 127.0.0.1:3080）。托盘图标可再次打开窗口。窗口不在前台时，会话跑完会发系统通知。
4. 对话和设置保存在当前 Windows 用户目录下的 .dsh，不在本文件夹里。
5. Chrome 侧边助手使用同一次打包产出的 dsh-side-assistant.zip：解压后在 chrome://extensions 打开开发者模式，加载已解压的 extension 目录。
6. 卸载：在「已安装的应用」里卸载，或双击本目录的 uninstall.cmd。只会删除本文件夹和快捷方式，不会删除 .dsh。

不需要安装 Node.js。首次启动会清理旧版托盘伴随程序。
